Fix slow Wi-Fi with one prompt

COMMENTED: ROUTER

  1. Open Claude Code on your computer (I used a Mac).
  2. Paste this prompt:
    My Wi-Fi feels slow. Run read-only checks on this computer: signal strength, nearby networks and their channels, ping to the router and the internet, DNS speed, and lag under load. Then tell me the one fix that matters most.
  3. Approve only the check commands. Mine took about 4 minutes.
  4. What the usual fixes mean:
    • Weak signal (around -70 dBm or worse): move closer to the router or use its 5 GHz network.
    • A neighbor on your channel: open your router's settings (often 192.168.0.1 or 192.168.1.1) and pick the empty channel Claude suggests.
    • Lag only when someone's downloading: turn on Smart Queue or SQM in the router, if it has it.
    • Slow DNS: switch to the faster server Claude found.
  5. Run the same prompt again and compare.

Clean your smart TV

COMMENTED: TV

Works on Android TV and Google TV only (not Samsung, LG, Roku).

  1. On the TV: Settings → Device Preferences → About. Press OK on "Build" 7 times.
  2. Go back → Developer options → turn on USB debugging. If you see Network or ADB debugging, turn that on too.
  3. On your computer (same Wi-Fi as the TV), get the free project:
    git clone https://github.com/Gathin23/cleanyourtv
  4. Open that folder in Claude Code (Codex or Gemini CLI work too).
  5. Paste everything from PROMPT.md and add your TV model.
  6. On the TV, accept "Allow USB debugging?"
  7. Answer its questions: which apps you use, what to keep. Takes about 15 min.

Before you start

  • Your computer needs Python 3, Java (JDK 17–22) and Android SDK 34. Ask Claude Code to check what's missing.
  • Nothing gets deleted. Apps are only disabled, and you get a restore script.
  • Go in small batches. Some TVs got stuck rebooting.
  • When you're done, turn USB debugging (and network debugging) back OFF.
  • Claude Code needs a paid plan. There's also a manual way in the README.

Set up a real Jarvis

COMMENTED: JARVIS

You need a computer with Chrome or Edge.

  1. Install Claude Code and log in: run claude once in a terminal. It needs a Claude subscription.
  2. Install Node.js 20 or newer from nodejs.org.
  3. Get the free project:
    git clone https://github.com/adewaskar/jarvis
  4. Open a terminal in that folder and run:
    npm install npm start
  5. Open the address it prints (http://localhost:5173) in Chrome or Edge. A real browser window, not a preview pane.
  6. Click INITIALISE, allow the microphone, and say "Hey Jarvis".

Good to know

  • No API keys. It runs on your Claude Code login, so usage counts toward your Claude plan.
  • Not sure you have everything? Run npm run setup in the folder and it checks for you.
  • Can't hear you? Press D for diagnostics, T for a sound test.
  • Space = talk without "Hey Jarvis". Just speak to interrupt it. Escape = stop.
  • Want a better voice? Add an ElevenLabs API key. Optional.
  • It starts read-only: it can search and generate, but it can't send, delete, install or pay.
  • npm start -- --writes turns actions on. Then its shell can reach anything your account can, so read "Enabling actions" in the README first.
